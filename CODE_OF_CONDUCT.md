# Code of Conduct

Spellbound adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct.

In addition, for this project specifically:

- Respect Deaf culture and ASL as a complete language. Don't frame deafness as a deficit to be fixed.
- Credit Deaf contributors' expertise and don't speak over it.
- Accessibility is part of conduct. Caption videos you share, and don't assume everyone hears audio.

**Reporting:** email anthony@WebDevofReality.com. Reports are handled confidentially.
